# 2026-05-24 学習ログ

## 今日学習したこと

今日は、JavaScriptの基本的な変数操作と標準入力の扱いを復習した。

---

## 1. 変数の更新処理

最初に、変数 `n` を使って以下の処理を行った。

```js
let n = 0;

n = n + 3286;
n = n * 4736;
n = n % 12312;

console.log(n);
```

### 学んだこと

`let` は「新しく変数を作る」ときに使う。

```js
let n = 0;
```

これは、`n` という変数を作って `0` を入れるという意味。

一度作った変数の中身を変更するときは、もう一度 `let` を付けない。

```js
n = n + 3286;
```

これは、今の `n` に `3286` を足して、その結果をもう一度 `n` に入れ直すという意味。

## 2. `let` を毎回つけてはいけない理由

以下のように、同じ変数名に何度も `let` を付けるとエラーになる。

```js
let n = 0;
let n = n + 3286;
```

`let` は変数を新しく作る命令なので、同じ場所で同じ名前の変数をもう一度作ろうとすると、

```text
Identifier 'n' has already been declared
```

のようなエラーになる。

### 理解したこと

- `let` は最初に変数を作るときだけ使う
- 変数の中身を更新するときは `let` を付けない
- `n = n + 3286` は「`n` の中身を更新する」という意味

## 3. 代入の考え方

今回の問題文では、

- N に `3,286` を足した値を N へ代入する
- N に `4,736` をかけた値を N へ代入する
- N を `12,312` で割った余りを N へ代入する

と書かれていた。

これは、新しい変数を作るのではなく、同じ N を順番に更新していくという意味。

### 計算の流れ

- `n = 0`
- `n = 0 + 3286` -> `3286`
- `n = 3286 * 4736` -> `15560896`
- `n = 15560896 % 12312` -> `6928`

最終的な出力は `6928` になった。

## 4. 省略した書き方

以下のように短く書けることも確認した。

```js
let n = 0;

n += 3286;
n *= 4736;
n %= 12312;

console.log(n);
```

### 意味

```js
n += 3286;
```

は、

```js
n = n + 3286;
```

と同じ意味。

```js
n *= 4736;
```

は、

```js
n = n * 4736;
```

と同じ意味。

```js
n %= 12312;
```

は、

```js
n = n % 12312;
```

と同じ意味。

## 5. 標準入力から文字列を受け取る問題

次に、入力された文字列をそのまま出力する問題を解いた。

```js
const fs = require("fs");
const input = fs.readFileSync(0, "utf-8").trim().split("\n");

let s = input[0];

console.log(s);
```

### 学んだこと

標準入力から1行の文字列を受け取る場合、`input[0]` にその文字列が入る。

例えば入力が `Paiza21` なら、`input[0]` には `Paiza21` が入る。

それを `console.log(s)` で出力すれば、入力された文字列をそのまま表示できる。

## 6. 1行入力だけなら短く書く方法

1行だけの入力なら、以下のようにも書ける。

```js
const fs = require("fs");
const s = fs.readFileSync(0, "utf-8").trim();

console.log(s);
```

ただし、今使っている `trim().split("\n")` の形は、今後「複数行入力」を扱うときにも使いやすいため、練習としては良い書き方。

## 今日の理解

今日は、変数の宣言と更新の違いを整理できた。

特に、

```js
let n = 0;
```

は変数を作る処理で、

```js
n = n + 3286;
```

は変数の中身を更新する処理だと理解した。

また、標準入力から受け取った文字列を `input[0]` で取り出し、そのまま出力する基本形も確認できた。

## 次に意識すること

- `let` は最初に変数を作るときだけ使う
- 変数を更新するときは `let` を付けない
- `=` は「同じ」という意味ではなく、「右側の結果を左側に代入する」という意味
- 標準入力では、1行目は `input[0]` に入る
