## 1. A, B, C を使って N を更新する問題

問題の流れ:

```text
N = 0
N = N + A
N = N * B
N = N % C
```

実装:

```js
let n = 0;
n = n + a;
n = n * b;
n = n % c;

console.log(n);
```

理解したこと:

- `n = n + a;` は「今の `n` に `a` を足して、再び `n` に代入する」処理
- `add`, `multi`, `remainder` のように別変数へ分けると、`n` 自体は更新されない
- この問題では毎回 `n = ...` と再代入することが重要

## 2. 電車の乗客人数を求める問題

問題の流れ:

- `a` 人乗っている
- `b` 人降りる
- `c` 人乗る
- 最終人数を出力する

実装（式で書く方法）:

```js
const answer = a - b + c;
console.log(answer);
```

実装（更新の流れを丁寧に書く方法）:

```js
let n = 0;
n = n + a;
n = n - b;
n = n + c;

console.log(n);
```

理解したこと:

- 入力が `a b c` のような1行スペース区切りなら `split(" ")`
- 入力が `A` / `B` / `C` のような行区切りなら `split("\n")`
- まず入力形式を見て、区切り文字を決めることが大切

## 3. 文字列 S が "paiza" と一致するか判定する問題

実装:

```js
const fs = require("fs");
const input = fs.readFileSync(0, "utf-8").trim().split("\n");

const s = input[0];

if (s === "paiza") {
  console.log("YES");
} else {
  console.log("NO");
}
```

理解したこと:

- 文字列一致の判定は `===` を使う
- `if / else` の基本形に沿って書けばよい

## 追記: if文の条件判定と入力値の読み取り

今日は paiza の標準入力問題を使って、if文の条件判定と入力値の読み取り方も学習した。

### 取り組んだ問題1

問題:

- 整数 `N` が与えられる
- `N` が `100` 以下なら `YES`、それ以外は `NO` を出力する

学んだコード:

```js
const fs = require("fs");
const input = fs.readFileSync(0, "utf-8").trim().split("\n");

const n = Number(input[0]);

if (n <= 100) {
  console.log("YES");
} else {
  console.log("NO");
}
```

学んだこと:

- `100` 以下は JavaScript では `n <= 100` と書く
- 最初に `if (n >= 100)` と書いてしまったが、これは `100` 以上の意味なので逆だった

### 取り組んだ問題2

問題:

- 整数 `A, B, C` が与えられる問題に取り組んだ
- 入力形式を見て、どの区切りで受け取るかを先に判断する練習をした

学んだこと:

- 横並び入力なら `split(" ")`
- 縦並び入力なら `split("\n")`
