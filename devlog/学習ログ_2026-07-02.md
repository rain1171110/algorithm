# 今日の学習ログ

## テーマ

JavaScriptで「1からNまでの数値を改行区切りで出力する」処理を復習した。

## 今日やったこと

今日は、入力された整数 `N` に応じて、`1` から `N` までの数値を改行区切りで出力する問題に取り組んだ。

最初は、入力配列 `input[i]` を出力しようとしていたが、この問題では入力される値は `N` だけなので、`input[i]` ではなく、for文のカウンター変数 `i` を出力する必要があると理解した。

また、`for` 文で `1` から `N` まで出力するためには、開始を `i = 1` にして、条件を `i <= n` にする必要があることを確認した。

## 今日の完成コード

```js
const fs = require("fs");
const input = fs.readFileSync(0, "utf-8").trim().split(/\s+/);

const n = Number(input[0]);

let result = "";

for (let i = 1; i <= n; i++) {
  result += i;

  if (i < n) {
    result += "\n";
  }
}

console.log(result);
```

## 入力例

```txt
2
```

## 出力例

```txt
1
2
```

## 今日理解したポイント

### 1. `input[0]` は文字列なので数値に変換する

```js
const n = Number(input[0]);
```

`readFileSync` で読み取った入力は文字列なので、数値として扱う場合は `Number()` を使う。

### 2. `input[i]` ではなく `i` を出力する

今回の問題では、入力されるのは `N` だけ。

そのため、`input[i]` を出力するのではなく、for文で作った `i` を出力する。

```js
result += i;
```

### 3. `i < n` と `i <= n` の違い

```js
for (let i = 1; i < n; i++)
```

これは `n` の手前まで。

```js
for (let i = 1; i <= n; i++)
```

これは `n` まで含む。

今回は「1からNまで出力する」ので、`i <= n` を使う。

### 4. 改行は `"\n"` を使う

```js
result += "\n";
```

`"\n"` は改行を表す。

半角スペース区切りなら `" "`、改行区切りなら `"\n"` を使う。

### 5. 最後に余計な改行を付けない

```js
if (i < n) {
  result += "\n";
}
```

最後の数字のあとに余計な改行を付けないために、`i < n` のときだけ改行を追加する。

## 今日出たエラー

```txt
ReferenceError: Cannot access 'result' before initialization
```

これは、`result` を作る前に `console.log(result);` を実行していたために発生したエラー。

`let result = "";` より前に `console.log(result);` を書くと、まだ `result` が存在しないのでエラーになる。

正しい順番は、先に変数を作って、最後に出力すること。

```js
let result = "";

// 処理を書く

console.log(result);
```
