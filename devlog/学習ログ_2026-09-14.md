# 2026-09-14 学習ログ：SET・ADD命令と入力の読み取り

## 今日やったこと

コンピュータの２つの変数を操作する問題に取り組んだ。最初は難しく感じたため、`SET` と `ADD` を小さな例で確認した。

```text
初期値       → 変数1 = 0、変数2 = 0
SET 1 5      → 変数1 = 5、変数2 = 0
ADD 3        → 変数1 = 5、変数2 = 8
```

## 理解できたこと

- `SET 1 5` の `1` は計算に使う数字ではなく、**変数の番号**。変数1に `5` を代入する。
- `ADD 3` は「変数1の値に `3` を足し、その結果を変数2に代入する」命令。変数1の値は変わらない。
- 変数は最初、どちらも `0`。

## 確認中のコード

```js
const fs = require("fs");
const lines = fs.readFileSync(0, "utf-8").trim().split(/\n+/);

let variable1 = 0;
let variable2 = 0;

const n = Number(lines[0]);

for (let i = 1; i <= n; i++) {
  const command = lines[i].split(" ");

  if (command[0] === "SET") {
    if (command[1] === "1") {
      variable1 = Number(command[2]);
    } else if (command[1] === "2") {
      variable2 = Number(command[2]);
```
