# 2026-09-15：SET・ADD・SUB命令の復習

## 0. 今日の目標

- SET・ADD・SUB命令による変数の変化を理解する
- 命令を上から順番に追えるようにする
- 実際のJavaScriptコードの読解へ進む

---

## 1. 今日学習した命令

```text
SET 1 a → V1にaを代入する
SET 2 a → V2にaを代入する
ADD a   → V2 = V1 + a
SUB a   → V2 = V1 - a
```

### 重要なポイント

- `SET`の後ろの`1`や`2`は、代入する値ではなく変数番号
- `ADD`と`SUB`では、V1は変化しない
- 計算結果はV2に代入される
- 以前のV2の値は使わず、新しい計算結果で上書きする

---

## 2. 最初に間違えた問題

```text
最初：V1 = 0、V2 = 0

SET 2 7
SET 1 4
ADD 5
```

### 正しい変化

```text
最初      → V1 = 0、V2 = 0
SET 2 7  → V1 = 0、V2 = 7
SET 1 4  → V1 = 4、V2 = 7
ADD 5    → V1 = 4、V2 = 4 + 5 = 9
```

### 最終結果

```text
V1 = 4
V2 = 9
```

### 間違えた原因

`ADD 5`でV1にも5を足してしまった。

しかし、この問題の`ADD 5`は、両方の変数に5を足す命令ではない。

```text
V2 = V1 + 5
```

V1はそのままで、V2だけが変化する。

---

## 3. ADDの確認問題

```text
最初：V1 = 0、V2 = 0

SET 1 6
SET 2 3
ADD 2
```

### 変数の変化

```text
SET 1 6 → V1 = 6、V2 = 0
SET 2 3 → V1 = 6、V2 = 3
ADD 2   → V1 = 6、V2 = 6 + 2 = 8
```

### 最終結果

```text
V1 = 6
V2 = 8
```

正しく回答できた。

---

## 4. SUBの確認問題

```text
最初：V1 = 0、V2 = 0

SET 1 10
SET 2 20
SUB 3
```

### 変数の変化

```text
SET 1 10 → V1 = 10、V2 = 0
SET 2 20 → V1 = 10、V2 = 20
SUB 3    → V1 = 10、V2 = 10 - 3 = 7
```

### 最終結果

```text
V1 = 10
V2 = 7
```

V2に入っていた`20`を使わず、`V1 - 3`の結果で上書きできることを理解した。

---

## 5. 複数命令の確認問題

```text
最初：V1 = 0、V2 = 0

SET 1 8
ADD 4
SET 1 15
SUB 5
```

### 変数の変化

```text
最初      → V1 = 0、 V2 = 0
SET 1 8  → V1 = 8、 V2 = 0
ADD 4    → V1 = 8、 V2 = 12
SET 1 15 → V1 = 15、V2 = 12
SUB 5    → V1 = 15、V2 = 10
```

### 最終結果

```text
V1 = 15
V2 = 10
```

命令が増えても、上から順番に正しく変化を追えた。

---

## 6. 今日の理解度

### 理解できたこと

- `SET 1`と`SET 2`の数字は変数番号である
- `SET`は指定された変数の値を上書きする
- `ADD a`は`V2 = V1 + a`
- `SUB a`は`V2 = V1 - a`
- `ADD`と`SUB`ではV1は変化しない
- 命令を1行ずつ追えば、複数の命令でも計算できる

### 今後注意すること

`ADD`という名前だけを見て、「両方の変数に足す」と判断しない。

必ず問題で決められたルールを確認する。

```text
ADD a → V2 = V1 + a
SUB a → V2 = V1 - a
```
