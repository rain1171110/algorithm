## 2. 今日理解した重要ポイント

### `SET`命令

```text
SET 2 8
```

- `2`：変数番号
- `8`：代入する値
- 結果：`variable2 = 8`
- `variable1`は変更されないため、初期値が`0`ならそのまま`0`

### `ADD`命令

```text
ADD 4
```

```javascript
variable2 = variable1 + 4;
```

元の`variable2`へ足すのではなく、`variable1 + 4`で上書きする。

### `SUB`命令

```text
SUB 2
```

```javascript
variable2 = variable1 - 2;
```

元の`variable2`から引くのではなく、`variable1 - 2`で上書きする。

### 入力の分割

```javascript
const lines = input.split("\n");
```

- `split("\n")`：改行ごとに分割する

```javascript
const command = lines[i].split(" ");
```

- `split(" ")`：半角スペースごとに分割する

たとえば、

```javascript
"SET 1 8".split(" ");
// ["SET", "1", "8"]
```

## 3. 完成コード

```javascript
const fs = require("fs");

const lines = fs
  .readFileSync(0, "utf-8")
  .trim()
  .split("\n");

let variable1 = 0;
let variable2 = 0;

const n = Number(lines[0]);

for (let i = 1; i <= n; i++) {
  const command = lines[i].split(" ");

  if (command[0] === "SET") {
    if (command[1] === "1") {
      variable1 = Number(command[2]);
    } else {
      variable2 = Number(command[2]);
    }
  } else if (command[0] === "ADD") {
    variable2 = variable1 + Number(command[1]);
  } else if (command[0] === "SUB") {
    variable2 = variable1 - Number(command[1]);
  }
}

console.log(variable1, variable2);
```

## 5. 間違えた点と修正

### 変数番号を代入する値と混同した

誤った考え方：

```text
SET 2 8 → variable1 = 2、variable2 = 8
```

正しい考え方：

```text
SET 2 8 → 2番の変数に8を入れる
         variable1 = 0、variable2 = 8
```

### `lines[0]`を最初の命令だと考えた

```javascript
lines[0] // 命令の個数
lines[1] // 1つ目の命令
```

そのため、`for`文は`i = 1`から開始する。

### `split("\n")`をスペース分割だと考えた

```javascript
split("\n") // 改行ごと
split(" ")  // スペースごと
```
