## 1. 今日の学習内容

### 命令のルール

- `SET i a`：変数`i`に`a`を代入する
- `ADD a`：`variable1 + a`の結果を`variable2`に代入する
- `SUB a`：`variable1 - a`の結果を`variable2`に代入する

`ADD`と`SUB`では、`variable1`の値は変化しない。

---

## 2. command配列の違い

### SETの場合

```javascript
"SET 2 8".split(" ");

// command[0] → "SET"
// command[1] → "2"
// command[2] → "8"
```

### ADD・SUBの場合

```javascript
"ADD 4".split(" ");

// command[0] → "ADD"
// command[1] → "4"
```

```javascript
"SUB 3".split(" ");

// command[0] → "SUB"
// command[1] → "3"
```

### 重要ポイント

`SET`は要素が3つあるため、代入する値は`command[2]`。

`ADD`と`SUB`は要素が2つしかないため、計算に使う値は`command[1]`。

---

## 3. 今日理解できた処理

### SET

```javascript
if (command[0] === "SET") {
  if (command[1] === "1") {
    variable1 = Number(command[2]);
  } else {
    variable2 = Number(command[2]);
  }
}
```

### ADD

```javascript
if (command[0] === "ADD") {
  variable2 = variable1 + Number(command[1]);
}
```

### SUB

```javascript
if (command[0] === "SUB") {
  variable2 = variable1 - Number(command[1]);
}
```

### 最後の値を表示

```javascript
console.log(variable1, variable2);
```

`console.log()`は、すべての命令を処理したあとに1回だけ実行するため、`for`ループの外側に書く。

## 4. 値が上書きされることを確認

次の命令を実行した。

```text
SET 1 10
ADD 4
SET 1 20
SUB 3
SET 2 50
```

処理の流れは次のとおり。

```text
SET 1 10 → 10, 0
ADD 4    → 10, 14
SET 1 20 → 20, 14
SUB 3    → 20, 17
SET 2 50 → 20, 50
```

最終結果：

```text
20 50
```

新しい値を代入すると、以前の値は上書きされる。

## 6. for文で修正した点

間違っていた条件：

```javascript
for (let i = 1; n <= i; i++) {
```

例えば`n = 3`、`i = 1`なら、`3 <= 1`は`false`になるため、ループが一度も実行されない。

正しい条件：

```javascript
for (let i = 1; i <= n; i++) {
```

「`i`が`n`以下の間、繰り返す」という意味になる。

各行の命令は、次のコードでスペースごとに分割する。

```javascript
const command = lines[i].split(" ");
```

## 8. 今日間違えた点

### ① ADDで`command[2]`を使った

```javascript
variable2 = variable1 + Number(command[2]);
```

`ADD 4`は`["ADD", "4"]`なので、`command[2]`は存在しない。

正しくは次のとおり。

```javascript
variable2 = variable1 + Number(command[1]);
```

### ② SUBで足し算を使った

```javascript
variable2 = variable1 + Number(command[1]);
```

`SUB`は引き算なので、正しくは次のとおり。

```javascript
variable2 = variable1 - Number(command[1]);
```

### ③ SUBをvariable2から引くと考えた

間違った考え方：

```text
現在のvariable2 - 値
```

正しい考え方：

```text
variable1 - 値 → variable2
```

`ADD`や`SUB`を実行すると、それまでの`variable2`の値は計算結果で上書きされる。

### ④ for文の条件を逆にした

```javascript
n <= i
```

ではなく、

```javascript
i <= n
```

と書く。
