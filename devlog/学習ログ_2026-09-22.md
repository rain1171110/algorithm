## 命令の形式

```text
SET i a
ADD a
SUB a
```

### SET

```text
SET 1 8
```

スペースで分割すると、次の配列になる。

```javascript
command[0]; // "SET"
command[1]; // "1"：変数番号
command[2]; // "8"：代入する値
```

`SET`では、`command[1]`を使って代入先を判断する。

```javascript
if (command[0] === "SET") {
  if (command[1] === "1") {
    variable1 = Number(command[2]);
  } else {
    variable2 = Number(command[2]);
  }
}
```

---

## ADD

```text
ADD 3
```

スペースで分割すると、次の配列になる。

```javascript
command[0]; // "ADD"
command[1]; // "3"：足す値
```

`ADD`には変数番号がない。

変数1に指定された数を足し、その結果を変数2へ代入する。

```javascript
} else if (command[0] === "ADD") {
  variable2 = variable1 + Number(command[1]);
}
```

### 例

```text
variable1 = 10
variable2 = 5
ADD 2
```

実行後：

```text
variable1 = 10
variable2 = 12
```

元の`variable2`は計算に使用しない。

---

## SUB

```text
SUB 4
```

スペースで分割すると、次の配列になる。

```javascript
command[0]; // "SUB"
command[1]; // "4"：引く値
```

変数1から指定された数を引き、その結果を変数2へ代入する。

```javascript
} else if (command[0] === "SUB") {
  variable2 = variable1 - Number(command[1]);
}
```

### 例

```text
variable1 = 15
variable2 = 100
SUB 5
```

実行後：

```text
variable1 = 15
variable2 = 10
```

次の計算ではないことに注意する。

```javascript
// 間違い
variable2 = variable2 - 5;

// 正しい
variable2 = variable1 - 5;
```

元の`variable2`は使用せず、計算結果で上書きする。

---

## SET・ADD・SUBの処理

```javascript
if (command[0] === "SET") {
  if (command[1] === "1") {
    variable1 = Number(command[2]);
  } else {
    variable2 = Number(command[2]);
  }
} else if (command[0] === "ADD") {
  variable2 = variable1 + Number(command[1]);
} else if (command[0] === "SUB") {
  variable2 = variable1 - Number(command[1]);
}
```

## 最終結果の出力

すべての命令を実行した後、2つの変数を表示する。

```javascript
console.log(variable1, variable2);
```

この処理は、結果を1回だけ表示するため`for`文の外側に書く。

```javascript
for (let i = 1; i <= n; i++) {
  // 命令を処理する
}

console.log(variable1, variable2);
```

## 今日間違えたポイント

### 1. ADDの数字を変数番号と考えてしまった

```text
ADD 2
```

この`2`は変数番号ではなく、足す値である。

```javascript
command[1]; // "2"：足す値
```

### 2. ADDでcommand[2]を使おうとした

```text
ADD 2
```

は2つの要素しかない。

```javascript
command[0]; // "ADD"
command[1]; // "2"
command[2]; // undefined
```

そのため、ADDとSUBでは`command[1]`を使用する。

### 3. ADDの中に不要なif文を書いた

ADDは代入先を選ばない。

計算結果は必ず`variable2`へ入るため、次の分岐は不要である。

```javascript
if (command[1] === "2") {
  // 不要
}
```

### 4. SUBをvariable2から引いてしまった

```javascript
// 間違い
variable2 = variable2 - Number(command[1]);

// 正しい
variable2 = variable1 - Number(command[1]);
```

---

## 現在の理解

- `SET`の`command[1]`は変数番号
- `SET`の`command[2]`は代入する値
- `ADD`の`command[1]`は足す値
- `SUB`の`command[1]`は引く値
- `ADD`と`SUB`は、計算結果を必ず`variable2`へ入れる
- `ADD`と`SUB`では、元の`variable2`を計算に使わない
- 最終出力は`for`文の外側に書く
