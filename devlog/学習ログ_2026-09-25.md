K氏のミニコンピュータ問題で、`SET`・`ADD`・`SUB` を処理するコードを完成させた。その後、何も見ずに最初から書き直して復習した。

- 入力を改行ごとに分け、`lines[0]` から命令数を取り出せた。
- 2つの変数を `0` で初期化し、`for` 文で命令を1行ずつ読むところまで自力で書けた。
- `SET` の処理で比較と代入を混同した。次回はここから再開する。

## 完成したコード

```js
const fs = require("fs");
const lines = fs.readFileSync(0, "utf-8").trim().split("\n");

const n = Number(lines[0]);

let variable1 = 0;
let variable2 = 0;

for (let i = 1; i <= n; i++) {
  const command = lines[i].split(" ");

  if (command[0] === "SET") {
    if (command[1] === "1") {
      variable1 = Number(command[2]);
    } else {
      variable2 = Number(command[2]);
    }
  } else if (command[0] === "ADD") {
    variable2 = variable1 + Number(command[1]);
  } else if (command[0] === "SUB") {
    variable2 = variable1 - Number(command[1]);
  }
}

console.log(variable1, variable2);
```

## 復習で確認したこと

`SET 1 10` を分割すると、`command[1]` は変数番号の文字列 `"1"`、`command[2]` は代入する値の文字列 `"10"` になる。

- `===`：同じ値かを調べる
- `=`：変数に値を入れる
- `Number(command[2])`：文字列を数値に変える

## 次回の開始地点

何も見ずに書き直している途中の、`SET` の内側から再開する。`command[1] === "1"` の場合は `variable1`、それ以外の場合は `variable2` に、`command[2]` を数値に変換して代入する。
