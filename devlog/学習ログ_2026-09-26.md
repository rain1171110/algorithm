## 1. SET命令の復習

例えば、

```txt
SET 1 5
```

を

```js
const command = lines[i].split(" ");
```

で分割すると、

```js
command[0] // "SET"
command[1] // "1"
command[2] // "5"
```

となる。

重要なのは、

```js
command[1]
```

は `variable1` そのものではなく、

**「どの変数を指定しているかを表す番号」**

ということ。

そのため、以下は間違い。

```js
if (command[1] === variable1) {
```

正しくは、

```js
if (command[1] === "1") {
```

となる。

---

## 2. command[2]を数値に変換する

最初は、

```js
variable1 = command[2];
```

と考えた。

しかし、

```js
command[2]
```

には、

```js
"5"
```

のような文字列が入っている。

そのため、

```js
Number(command[2])
```

として数値へ変換する。

```js
variable1 = Number(command[2]);
```

---

## 3. SET処理の完成

今日完成したSET処理。

```js
if (command[0] === "SET") {
  if (command[1] === "1") {
    variable1 = Number(command[2]);
  } else {
    variable2 = Number(command[2]);
  }
}
```

例えば、

```txt
SET 1 10
```

なら、

```js
variable1 = 10;
```

となる。

一方、

```txt
SET 2 8
```

なら、

```js
variable2 = 8;
```

となる。

## 4. for文の動き

現在使っている処理。

```js
for (let i = 1; i <= n; i++) {
  const command = lines[i].split(" ");
}
```

この部分がまだ少し複雑に感じるため、仕組みを確認した。

例えば入力が、

```txt
3
SET 1 10
ADD 5
SUB 2
```

だった場合、

```js
lines[0] // "3"
lines[1] // "SET 1 10"
lines[2] // "ADD 5"
lines[3] // "SUB 2"
```

となる。

そして、

```js
const n = Number(lines[0]);
```

によって、

```js
n = 3;
```

となる。

for文では、

```js
i = 1
i = 2
i = 3
```

と変化する。

### 1回目

```js
i = 1;

lines[1];
// "SET 1 10"

const command = lines[1].split(" ");

// command
["SET", "1", "10"]
```

### 2回目

```js
i = 2;

lines[2];
// "ADD 5"

const command = lines[2].split(" ");

// command
["ADD", "5"]
```

### 3回目

```js
i = 3;

lines[3];
// "SUB 2"

const command = lines[3].split(" ");

// command
["SUB", "2"]
```

つまり、

```js
lines[i]
```

の `i` が、

```txt
1 → 2 → 3
```

と変化することで、

**命令を上から1行ずつ取り出して処理している。**

---

## 今日の重要ポイント

```js
command[1] === "1"
```

は、

**「変数1が指定されているか？」**

を確認している。

```js
variable1 = Number(command[2]);
```

は、

**「指定された値を数値に変換してvariable1へ入れる」**

という意味。

そして、

```js
for (let i = 1; i <= n; i++) {
  const command = lines[i].split(" ");
}
```

は、

**命令を1行目 → 2行目 → 3行目……と順番に取り出す処理。**

---

## 現在の理解

SET処理については、

```js
if (command[0] === "SET") {
  if (command[1] === "1") {
    variable1 = Number(command[2]);
  } else {
    variable2 = Number(command[2]);
  }
}
```

まで自力で組み立てられた。

一方で、

```js
for (let i = 1; i <= n; i++) {
  const command = lines[i].split(" ");
}
```

が実際にどのような順番で動いているのかは、もう少し反復して理解を固める。
