## 2. 今日理解したこと

### 命令は上から順に実行され、変数の値は保持される

```text
4
SET 1 10
ADD 5
SET 1 3
SUB 2
```

| 実行後 | 変数1 | 変数2 |
| --- | ---: | ---: |
| 初期値 | 0 | 0 |
| `SET 1 10` | 10 | 0 |
| `ADD 5` | 10 | 15 |
| `SET 1 3` | 3 | 15 |
| `SUB 2` | 3 | 1 |

`SUB 2` は変数2の古い値 `15` から引くのではなく、`variable1 - 2` の結果を変数2に代入する。

### `lines[i]` と `command` は違う

```js
lines[2]; // "SUB 2"

const command = lines[2].split(" ");
console.log(command); // ["SUB", "2"]
```

`lines[2]` は1行の文字列。`split(" ")` 後の `command` は、命令と値に分かれた配列。

### `Number()` は足す前に文字列へ使う

```js
const variable1 = 6;
const command = ["ADD", "4"];

Number(variable1 + command[1]); // 64
variable1 + Number(command[1]); // 10
```

`variable1` は数値の `6`、`command[1]` は文字列の `"4"`。`6 + "4"` は文字列の `"64"` になるため、先に `command[1]` を数値へ変換する。

```js
variable2 = variable1 + Number(command[1]);
```

## 3. 自分が間違えた点と修正

- `SET 1 3` の後も変数1を `10` と考えた。`SET` は指定された変数の値を上書きするので、実行後は `(3, 15)`。
- `ADD 5` の `5` だけを変数2へ入れると考えた。実際は、その時点の変数1に `5` を足した結果を代入する。
- `Number(variable1 + command[1])` と書いた。先に文字列の結合が起きるため、`variable1 + Number(command[1])` に修正する。
