## 2. 今日理解したこと

### ① 数値へ変換してから計算する

`command[1]` は文字列なので、`Number()` で数値へ変換してから足す。

```js
variable2 = variable1 + Number(command[1]);
```

例えば、変数1が `10`、`command[1]` が `"5"` の場合：

```js
10 + Number("5"); // 15
```

### ② ADD・SUBの結果は変数2に入れる

| 命令 | 処理 |
|---|---|
| `SET i a` | 指定された変数に値を入れる |
| `ADD a` | 変数1にaを足し、結果を変数2に入れる |
| `SUB a` | 変数1からaを引き、結果を変数2に入れる |

ADD・SUBでは、変数1は変わらない。

### ③ 変数2の値は上書きされる

```text
SET 1 10
ADD 5
SUB 3
```

| 命令 | variable1 | variable2 |
|---|---:|---:|
| 初期状態 | 0 | 0 |
| SET 1 10 | 10 | 0 |
| ADD 5 | 10 | 15 |
| SUB 3 | 10 | 7 |

`SUB 3` は、直前の変数2の値 `15` から引くのではなく、変数1の `10` から引く。

## 3. 間違えたところと修正

### ADDの代入先

最初は、変数1に計算結果を入れていた。

```js
if (command[0] === "ADD") {
  variable1 = variable1 + Number(command[1]);
}
```

仕様に合わせて、代入先を変数2へ修正した。

```js
if (command[0] === "ADD") {
  variable2 = variable1 + Number(command[1]);
}
```

### SUBの命令名と代入先

最初は、引き算の条件を `"SET"`、代入先を `variable1` としていた。

修正後は、条件を `"SUB"`、代入先を `variable2` として正しく書けた。

```js
if (command[0] === "SUB") {
  variable2 = variable1 - Number(command[1]);
}
```

## 4. 今日確認したコード

```js
if (command[0] === "ADD") {
  variable2 = variable1 + Number(command[1]);
} else if (command[0] === "SUB") {
  variable2 = variable1 - Number(command[1]);
}
```

- `command[0]`: 命令名
- `command[1]`: ADD・SUBで使用する値
- `Number(command[1])`: 文字列を数値へ変換
- `variable2 = ...`: 計算結果を変数2へ代入
