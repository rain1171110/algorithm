## 2. 今日の気づき・理解したこと

### 配列の添字と変数番号は別

最初は、`command[2]`を「変数2」と考え、値は`command[3]`に入っていると思っていた。

実際には、添字は分割した文字列の位置を表す。添字は0から始まる。

```js
// SET 2 20 → ["SET", "2", "20"]

command[0]; // "SET"：命令
command[1]; // "2"：代入先の変数番号
command[2]; // "20"：代入する値
command[3]; // undefined：存在しない
```

SETでは、`command[1]`の中身を条件分岐で確認し、代入先を選ぶ。
どちらの変数に入れる場合も、値は`command[2]`から取る。

### 命令によって値の位置が違う

| 命令 | 分割後 | 値の位置 |
| --- | --- | --- |
| SET 2 20 | `["SET", "2", "20"]` | `command[2]` |
| ADD 3 | `["ADD", "3"]` | `command[1]` |
| SUB 2 | `["SUB", "2"]` | `command[1]` |

「配列の2番目」ではなく、「添字2＝3番目の要素」と区別して説明する。

### ADD・SUBは変数2を上書きする

ADD・SUBは、変数1を使って計算し、結果を変数2へ代入する。
変数2の以前の値に足したり引いたりする処理ではない。
