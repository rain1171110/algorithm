K氏のミニコンピュータ問題を、前回の続きから進めた。命令行を空白で分割し、`SET` の処理を実装した。`if` の条件で値を比較するときは `===` を使うことを確認した。

## 今日理解したこと

- `SET 1 10` は `["SET", "1", "10"]` になる。
- `SET` は命令・変数番号・値の3つに分かれる。
- `ADD` と `SUB` は、命令と数値の2つに分かれる。
- 配列の要素番号は `0` から始まる。
- `ADD` と `SUB` で数値が入る位置は、次回もう一度確認する。

## 今日書いたコード

```javascript
for (let i = 1; i <= n; i++) {
  const command = lines[i].trim().split(" ");

  if (command[0] === "SET") {
    if (command[1] === "1") {
      variable1 = Number(command[2]);
    } else {
      variable2 = Number(command[2]);
    }
  } else if (command[0] === "ADD") {
    variable2 = variable1 + Number(command[2]); // 引数の位置は要確認
  } else if (command[0] === "SUB") {
    variable2 = variable1 - Number(command[2]); // 引数の位置は要確認
  }
}
```
