## 3. 実装・技術の要点

- 重要なコードまたはコマンド：

```js
const fs = require("fs");
const lines = fs.readFileSync(0, "utf-8").trim().split(/\n+/);

let variable1 = 0;
let variable2 = 0;

const n = Number(lines[0]);

for (let i = 1; i <= n; i++) {
  const command = lines[i].trim().split(" ");

  if (command[0] === "SET") {
    if (command[1] === "1") {
      variable1 = Number(command[2]);
    } else {
      variable2 = Number(command[2]);
    }
  } else if (command[0] === "ADD") {
    variable2 = variable1 + Number(command[1]);
  } else if (command[0] === "SUB") {
    variable2 = variable1 - Number(command[1]);
  }
}

console.log(variable1, variable2);
```

- 責務・目的：標準入力を行ごとに読み、命令を解釈して2つの変数を更新し、結果を出力する。
- 入力：1行目に命令数、続く行に`SET`・`ADD`・`SUB`の命令。
- 出力：最後の`variable1`と`variable2`。`console.log`はスペース区切りで出力する。問題の出力例との一致は未確認。
- 副作用：標準入力を読み取り、標準出力へ結果を出力する。
- 型の絞り込み（該当する場合）：`command[0]`の文字列比較で命令の種類を分岐する。JavaScriptのため静的な型絞り込みは該当なし。
- null／undefinedの扱い（該当する場合）：該当なし。
- 型で守れていること：該当なし（JavaScript）。
- 似た書き方との違い：`SET`は`command[1]`が変数番号、`command[2]`が代入値。`ADD`・`SUB`は`command[1]`が計算に使う数値。
- 今日理解したこと：`trim()`で行末の空白を取り除き、`split(" ")`で命令を空白ごとに分ける。`SET`・`ADD`・`SUB`を`if`／`else if`で分岐する。

## 学んだこと

### 1. 基本事項

### 2. コードの意味

```js
const command = lines[i].trim().split(" ");
```

- このコードは1行の命令文字列を空白で分解し、`command[0]`に命令名、`command[1]`に番号や引数、`command[2]`に値が入るようにする処理である。
- 命令の種類ごとに処理を切り替えるために必要であり、`SET`・`ADD`・`SUB`を一つずつ判定しやすくする。

### 3. 問題の考え方

- 命令を順番に処理するために、入力の1行目にある命令数`n`をまず確認した。
- その後、`i = 1`から`i <= n`までループし、各命令に対して`if / else if`で分岐させる考え方で解いた。
- `SET`の代入先と値の位置、`ADD`・`SUB`の更新先を意識して、各命令の役割を整理した。

## 今日のポイント

- 命令を分割した後の配列の位置は、命令ごとに意味が異なる。
- `for`ループの境界を間違えると、最後の命令を処理できない。
- `if`と`else if`で処理を分岐させると、命令ごとの変数更新が明確になる。
- `SET`と`ADD`/`SUB`の代入先が違うので、変数を更新する位置を明確にする必要がある。
