## 3. 実装・技術の要点

### 重要なコード：レベル計算

```js
const fs = require("fs");
const input = fs.readFileSync(0, "utf-8").trim().split(/\s+/);

const n = Number(input[0]);
let currentLevel = Number(input[1]);

for (let i = 0; i < n; i++) {
  const opponentLevel = Number(input[i + 2]);

  if (currentLevel > opponentLevel) {
    currentLevel = currentLevel + Math.floor(opponentLevel / 2);
  } else if (currentLevel < opponentLevel) {
    currentLevel = Math.floor(currentLevel / 2);
  }

  console.log(`相手:${opponentLevel}, 更新後:${currentLevel}`);
}

console.log(currentLevel);
```

- 責務・目的：
  - 相手と順番に対戦し、自分のレベルを更新する。
  - 各対戦後のログと最終レベルを表示する。
- 入力：
  - `input[0]`：対戦回数
  - `input[1]`：初期レベル
  - `input[2]` 以降：相手レベル
- 出力：
  - ループ内：各対戦の相手レベルと更新後のレベル
  - ループ外：最終レベル
- 更新ルール：
  - 自分が高い：相手レベルの半分を切り捨てて加算する。
  - 自分が低い：自分のレベルを半分にして切り捨てる。
  - 同じ：どちらの条件にも入らず、そのまま維持する。

### 重要なコード：ポイント還元計算

```js
const fs = require("fs");
const input = fs.readFileSync(0, "utf-8").trim().split(/\s+/);

const n = Number(input[0]);
let x = Number(input[1]);

let currentPoint = n;
let usagePoint = 0;

for (let i = 0; i < 7; i++) {
  usagePoint = usagePoint + currentPoint;
  currentPoint = Math.floor(Number((currentPoint * x) / 100));
}

console.log(usagePoint);
```

- 責務・目的：7日間、毎日すべてのポイントを使った場合の使用累計を求める。
- 入力：
  - `n`：最初のポイント数
  - `x`：還元率（％）
- 出力：7日間で使ったポイントの累計 `usagePoint`
- 処理の順番：
  1. 今日使う `currentPoint` を `usagePoint` に加える。
  2. `currentPoint × x ÷ 100` を切り捨て、翌日のポイントとして保存する。
- 7日目に計算する還元ポイントは8日目の分なので、今回の累計には加算されない。
- 会話で確認した例：
  - 初期ポイント `1024`、還元率 `50`％
  - 7日間の使用ポイントは `1024、512、256、128、64、32、16`
  - 累計は `2032`
  - これはコードの説明として確認した値であり、手元での実行結果は未記録。

### 1. 基本事項

- `if` と `else if` で条件分岐し、勝敗や累計の計算を表す方法を理解した。

### 2. コードの意味

```js
const input = fs.readFileSync(0, "utf-8").trim().split(/\s+/);
```

- このコードは、標準入力を受け取り、前後の空白を削ってから空白区切りで配列化する処理である。
- その後、`input[0]` や `input[i + 2]` のように、必要なデータを取り出して計算に使えるようにするために使う。

### 3. 問題の考え方

- 今回は、入力の並びを確認して「何を何回処理するか」を整理し、最初の値と繰り返し回数を分けて考えることが重要だった。
- 相手レベルごとに現在のレベルを更新し、最終的な値を出力する。ポイント計算では「今日使う分」を加算してから「翌日の還元」を計算する順序が大事だった。
