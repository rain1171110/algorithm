## 2. 問題を自分の言葉で整理する

最初のポイント数 N と還元率 X（%）を受け取り、毎日手持ちのポイントをすべて使ったときの7日間の合計を出力する。還元分は小数点以下を切り捨て、翌日から使える。入力値の範囲は未確認。

入力が `10 30` なら、1日目に10、2日目に3を使う。3日目は `Math.floor(3 * 30 / 100)` で0になるため、合計は13。

## 3. 解き方を考える

1. 今日使えるポイントを N、累計を0で初期化する。
2. 今日使うポイントを累計に足す。
3. 還元率を掛けて100で割り、小数点以下を切り捨てた値を翌日分として保存する。手順2と3を7日分繰り返す。

各日のループ開始時に、残高には今日使うポイントが、累計には前日までの使用分が入っている。この順番で更新すると翌日も同じ関係が保たれ、7回目で7日目の使用分まで足せる。

## 4. 実装とコードの理解

チャットで書いた完成コード。

```js
const fs = require("fs");
const input = fs.readFileSync(0,"utf-8").trim().split(/\s+/);

const firstPoint = Number(input[0]);
const rate = Number(input[1]);
let currentPoint = firstPoint;
let total = 0;

for (let i = 1; i <= 7; i++) {
  total = total + currentPoint;
  currentPoint = Math.floor(currentPoint * rate / 100);
}

console.log(total);
```

- `firstPoint` と `rate` は標準入力から取得する。分割した値は `Number()` で数値に変換する。
- `currentPoint` は今日使うポイントで、ループの最後に翌日分へ更新する。`total` は使ったポイントの累計。
- 集計の時間計算量は O(1)、追加領域は O(1)。ループは固定の7回で、日ごとの値を配列に保存する必要はない。

## 6. つまずきと修正

| 起きたこと | 原因 | 修正したこと |
| --- | --- | --- |
| 日ごとの還元分を計算できなかった | 日数を表す `i` を半分にしていた | `currentPoint` を還元計算に使った |
| 合計が1016になった | 今日の値を翌日分で上書きしてから足した | 今日の使用分を足してから、翌日分を計算した |
| 入力を読み込んでも結果が固定だった | 初期ポイントと還元率を固定値にしていた | 入力の先頭2項目を数値に変換して使った |

元の順番では1日目に512を足すため、2日目から8日目に相当する値を集計していた。正しい合計2032から1日目の1024が抜け、余分な8が入ると1016になる。

## 7. 解説・前回の解答と比較する
