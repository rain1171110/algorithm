## ポイント還元セールの応用

### 1. 問題と今回の結果

初回の点数、還元率、回数の上限を読み取る。点数がゼロになったら途中で終了し、合計点と実際に足した回数を同じ行に出力する。ヒントを使って途中終了と回数の集計まで実装した。

### 3. 解き方を考える

1. `currentPoint` に初回の点数を入れ、`total` と `count` をゼロにする。
2. `currentPoint` がゼロなら、点数を足す前に `break` する。
3. 点数を足した直後に `count++` し、`Math.floor((currentPoint * rate) / 100)` で次の点数を求める。
4. ループの後で `console.log(total, count)` を実行する。

### 5. 動作確認と境界条件

PowerShell で `"15 50 100" | node .\point-review.js` を実行し、合計が `26` になることを確認した。点数は `15 → 7 → 3 → 1 → 0` と変わる。

| 入力 | 回数を追加した版の期待出力 | 確認する条件 |
| --- | --- | --- |
| `15 50 100` | `26 4` | 点数が途中でゼロになる |
| `0 50 100` | `0 0` | 最初の判定で終了する |
| `1024 50 3` | `1792 3` | 回数の上限に達する |

### 6. つまずきと修正

途中版では `0 50 100` を入力したときに上限の `100` が表示された。点数を足した回数を `count` に記録し、最後に合計と一緒に表示するようにした。

## 偶数の個数を数える

### 1. 問題と今回の結果

1行目に整数の個数 `n`、2行目に `n` 個の整数を受け取り、偶数の個数を出力する。ヒントを使って、入力を順番に読む添字を修正できた。

### 4. 実装とコードの理解

```js
const n = Number(input[0]);
let count = 0;

for (let i = 0; i < n; i++) {
  const num = Number(input[i + 1]);
  if (num % 2 === 0) {
    count++;
  }
}
console.log(count);
```

各整数を1回ずつ調べるため、時間計算量は O(n)。入力配列を除いた追加領域は O(1)。

### 5. 動作確認と境界条件

整数が `3 8 0 7 12` のとき、`8`、`0`、`12` が偶数なので期待出力は `3`。

### 6. つまずきと修正

`input[1]` と `input[n + 2]` はどちらもループ中に読む位置が変わらない。`input[0]` は個数なので、ループごとに変わる `i` を使って `input[i + 1]` と書くと、`input[1]` から `input[n]` まで順に読める。

## 10. 3行まとめ

1. ループの上限を `num` に持ち、実際に処理した回数は `count` に記録した。
2. `input[0]` に個数があるときは、インデックスを `i + 1` にして各整数を順番に読んだ。
3. 次の解き直しでは、最初と最後に読む添字を確認してからループを書く。
