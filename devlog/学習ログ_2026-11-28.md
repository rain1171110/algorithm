- その他 → "One Pair" の判定

## 見つかった問題 🐛

### 大きな問題：`hand` 変数が定義されていない

**現在のコード：**
```javascript
for (let i = 0; i < n; i++) {
  if (hand[0] === hand[3]) {  // ← hand はここで定義されていない！
    console.log("fourCard");
  }
  // ...
}
```

ループの中で `hand` を使っているのに、どこからも手札データを取得していません。

**解決方法のヒント：**
- `input` 配列には全ての手札データが入っている
- `input[0]` は N（手札の枚数）
- `input[1]` は 1 番目の手札
- `input[2]` は 2 番目の手札
- ...つまり `input[i + 1]` が i 番目のループで使う手札

---

## 判定ロジックの検討

### 現在の判定順序
1. 4枚全部同じ？ → Four Card
2. 最初の3枚が同じ？ → Three Card
3. ペア2つ？ → Two Pair
4. それ以外 → One Pair

**ただし注意：**
- 判定順序が大事（最初の if に当てはまらなかったら次の else if へ）
- "No Pair"（4枚全部異なる）の判定がまだない
